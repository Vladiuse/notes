# Хоткеи сворачивания (folding) в VSCode

## Основные

| Хоткей | Действие |
|---|---|
| `Ctrl+Shift+[` | Свернуть блок под курсором |
| `Ctrl+Shift+]` | Развернуть блок под курсором |
| `Ctrl+K Ctrl+0` | Свернуть всё в файле |
| `Ctrl+K Ctrl+J` | Развернуть всё |

## По уровням вложенности

Чаще всего нужно в Python:

| Хоткей | Действие |
|---|---|
| `Ctrl+K Ctrl+1` | Свернуть до 1-го уровня (только `class`/`def` верхнего уровня) |
| `Ctrl+K Ctrl+2` | До 2-го (видны методы внутри классов, тела свёрнуты) |
| ... | ... |
| `Ctrl+K Ctrl+7` | До 7-го уровня |

Для `services.py` с кучей сервисов `Ctrl+K Ctrl+2` даёт удобный обзор:
все классы с их методами, без тел.

## Полезное сверх этого

| Хоткей | Действие |
|---|---|
| `Ctrl+K Ctrl+-` | Свернуть все блоки *того же уровня*, что и текущий (остальные не трогает) |
| `Ctrl+K Ctrl+/` | Свернуть все комментарии/докстринги |
| `Ctrl+K Ctrl+,` | Свернуть выделенный диапазон (folding range from selection) |

Свёрнутый через `Ctrl+K Ctrl+,` диапазон разворачивается обычным `Ctrl+Shift+]`.

## Мышью

То же самое — стрелки в жёлобе слева от номеров строк.
Если их не видно, они появляются на ховер.
